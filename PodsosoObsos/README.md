# PodsosObsos — Antigravity & agy CLI Patcher v1.4.0

Документация и руководство пользователя находятся в корневом файле `README.md`.

Быстрый запуск в один клик:
- macOS: `python3 common/podsoso_obsos.py --all`
- Linux: `python3 common/podsoso_obsos.py --all`
- Windows: `python common\podsoso_obsos.py --all`

Полный откат в один клик:
```bash
python3 common/podsoso_obsos.py --restore
```

Диагностика системы:
```bash
python3 common/podsoso_obsos.py --diagnostics
```

Управление службой локального прокси:
```bash
python3 common/podsoso_obsos.py --proxy-status
python3 common/podsoso_obsos.py --proxy-start
python3 common/podsoso_obsos.py --proxy-stop
```
